# Reporting a Vulnerability

If you discover a security vulnerability in `@artus-engineering/n8n-nodes-loki`, please report it responsibly.

**Preferred:** Open a [GitHub Security Advisory](https://github.com/artus-engineering/n8n-nodes-loki/security/advisories/new) (private disclosure).

**Alternative:** Email [hi@artus-engineering.de](mailto:hi@artus-engineering.de) with a description of the issue and steps to reproduce.

Please do not open a public issue for security vulnerabilities.

We aim to acknowledge reports within a few business days and will work with you on a fix and coordinated disclosure where appropriate.

Thank you for helping keep this project and its users safe.
